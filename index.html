Why Binary Arithmetic?

Digital electronic circuits use transistors as switches that only understand two physical states: ON (1) and OFF (0). All complex operations, graphics, and algorithms in computers are reduced to logic gate additions at the hardware level.

The Need for Complements

Designing separate hardware subtractor circuits is costly and inefficient. By converting subtraction problems into addition problems using complement representation, CPUs can perform both addition and subtraction using the exact same adder circuitry (ALU).

1's vs 2's Complement

While 1's complement simply flips all bits, it has a drawback: it produces two representations for zero (+0 and -0) and requires an end-around carry. 2's Complement solves this by adding 1, giving a single zero and cleaner hardware implementation.

3. Steps for 1's Complement Subtraction (A - B)

  1. Find the 1's complement of subtrahend B by inverting all bits (0s to 1s, 1s to 0s).
  2. Add this inverted value to A using standard binary addition.
  3. Check for End-Around Carry:
    • If a carry out exists: Add 1 to the result (End-Around Carry). Answer is positive.
    • If no carry out: Take 1's complement of the result and put a negative (-) sign.

4. Steps for 2's Complement Subtraction (A - B)

  1. Find the 1's complement of B by inverting bits.
  2. Add 1 to get the 2's complement of B.
  3. Add the 2's complement result to A.
  4. Evaluate Carry Bit:
    • If carry out exists: Discard the carry. Result is positive.
    • If no carry out: Take 2's complement of final result; value is negative.
